# 🧪 나만의 AI 화학실험실

위험한 시약 없이 **가상 비커**에서 화학 반응을 실험하고, **AI 조교(Claude)** 에게 원리를 물어보는 웹 앱입니다.

## 기능

- **시약 선반** — 산·염기·금속·지시약 등 18가지 시약. 각 시약의 위험 표시(부식성, 산화성, 독성…)와 설명.
- **가상 비커** — 시약을 넣으면 색 변화, 기포, 앙금, 금속 석출, 거품(코끼리 치약), 온도 변화가 애니메이션으로 나타납니다.
- **반응 데이터베이스** — 중화, 금속+산, 금속 치환, 앙금 생성, 분해 반응 등 23가지 반응과 반응식·원리 설명.
- **안전 교육** — 락스+암모니아, 락스+산처럼 *현실에서 절대 섞으면 안 되는* 조합은 빨간 경고와 사고 대처법을 보여 줍니다.
- **지시약** — 페놀프탈레인, 적양배추 지시약 색이 비커의 산성/염기성에 따라 바뀝니다.
- **AI 반응 예측** — 데이터베이스에 없는 조합은 Claude가 예측해 비커에 그려 줍니다 (“AI 예측” 표시).
- **AI 조교 채팅** — 반응 원리를 학생 눈높이로 설명. 위험한 제조법 등은 안내하지 않도록 설정되어 있습니다.
- **실험 노트** — 했던 실험이 자동으로 기록됩니다.
- **앱처럼 설치(PWA)** — 휴대폰 “홈 화면에 추가”로 설치 가능, AI 외 기능은 오프라인에서도 동작.

## 실행 방법

빌드가 필요 없는 정적 웹 앱입니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기
```

GitHub Pages, Netlify 같은 정적 호스팅에 그대로 올려도 됩니다.

## AI 기능 켜기

1. [Anthropic 콘솔](https://console.anthropic.com/)에서 API 키를 발급합니다.
2. 앱 오른쪽 위 **⚙️ 설정**에 키를 입력합니다.

키는 그 브라우저의 localStorage에만 저장되고 Anthropic API로만 전송됩니다. 사용량에 따라 요금이 청구되니, 앱을 다른 사람에게 공개 배포할 때는 키를 브라우저에 넣는 대신 작은 서버(프록시)를 두는 방식을 권장합니다.

## 구조

```
index.html          화면
css/style.css       스타일 (다크 모드, 모바일 대응)
js/chemicals.js     시약 목록
js/reactions.js     반응 데이터베이스 (여기에 반응을 추가하면 됩니다)
js/ai.js            Claude 연동 (채팅, 반응 예측)
js/app.js           비커 시뮬레이션과 화면 동작
sw.js, manifest     PWA 설정
```

## 반응 추가하기

`js/reactions.js`에 `add('시약id1', '시약id2', { ... })` 한 줄을 추가하면 됩니다. 새 시약은 `js/chemicals.js`에 추가하세요.
